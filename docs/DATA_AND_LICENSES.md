# Data, models, and artifacts

This repository contains source code and compact aggregate results only. It does
not redistribute datasets, image features, raw dialogues, belief artifacts,
model weights, or experiment logs containing private filesystem locations.

To reproduce a result, obtain every external dataset and checkpoint directly
from its original provider and comply with that provider's terms. The default
text encoder is Salesforce BLIP ITM Large COCO at a pinned revision; its model
card and upstream license govern its use.

Before a public release, replace `LICENSE_PENDING.md` with the authors' chosen
software license. Do not include data or third-party model artifacts merely by
adding a code license.
