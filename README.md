# NACIR: Negative-aware Adaptive Concept Interactive Retrieval

Official implementation of the paper **NACIR: Negative-aware Adaptive Concept Interactive Retrieval** for multi-turn conversational image retrieval.

## 🌟 Highlights
- **Dynamic Concept Graph (DCG):** Resolves Semantic Leakage in deep conversational turns (Turn 10).
- **Counterfactual Purging:** Mitigates hallucinated concepts generated by LLM parsers.
- **Adaptive Vector Surgery:** Eradicates the Negation Blindness issue in foundational VLMs via Orthogonal Projection.
- **Learned Attention Scheduler:** Dynamically calibrates interaction weights across the dialogue.

## 📂 Repository Structure
- `src/nacir/`: Core architecture containing DCG, Adaptive Scheduler, and configuration logic.
- `src/adapters/`: Adapters for orthogonal projection, semantic parsers, and cross-attention mechanisms.
- `src/run_nacir.py`: Main evaluation entry point.
- `scripts/`: Ready-to-use Bash scripts for testing different LLMs (LLaMA-3.1 8B, Gemma-3 4B, etc.).

## 🚀 Quick Start
```bash
# Evaluate with LLaMA-3.1 8B backbone
bash scripts/run_eval_llama3.1_8b.sh

# Evaluate with Gemma-3 4B backbone
bash scripts/run_eval_gemma3_4b.sh
```
