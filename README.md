# NACIR++: Non-Forgettable Conversational Image Retrieval with Semantic Concept Memory

Official PyTorch implementation for **NACIR++**, a State-Of-The-Art framework for Conversational Image Retrieval (CIR). NACIR++ resolves the "catastrophic forgetting" problem in multi-turn dialog retrieval through explicit Concept Memory, Orthogonal Projection against negative beliefs, and deep cross-modal ITM Re-ranking.

## Highlights
- **State-Of-The-Art Performance**: Achieves **92.44% Hits@10** and **76.70% Recall@10** at Turn 10 on VisDial v1.0.
- **Concept Memory**: Dynamically updates and retains semantic beliefs across multi-turn dialogs.
- **Negative Orthogonal Projection**: Projects visual queries away from unwanted semantic attributes (negative beliefs).
- **Two-Stage Retrieval**: Ultra-fast global cosine similarity filtering followed by precise BLIP Image-Text Matching (ITM) Re-ranking.

## 1. Setup & Installation

Clone the repository and install the dependencies:
```bash
git clone https://github.com/your-username/NACIR-PlusPlus.git
cd NACIR-PlusPlus/Source_code
pip install -r requirements.txt
```

## 2. Data Preparation

Before running the evaluation, you must set up the paths in `main.py`. Open `main.py` and modify the following configuration variables to point to your local dataset files:

```python
# Config (main.py)
DATA_DIR = "/Path_to_your_data_directory"
QUERIES_PATH = "/Path_to_your_queries_file.json"
PLUGIR_QUERIES_PATH = "/Path_to_your_plugir_queries_file.json"
CACHE_CORPUS_PATH = "/Path_to_your_corpus_cache_file.pt"
CORPUS_PATH = "/Path_to_your_corpus_file.json"
BELIEFS_PATH = "/Path_to_your_beliefs_file.json"
OUTPUT_DIR = "/Path_to_your_output_directory"
```

**Note on Semantic Beliefs:**
The file `semantic_beliefs.json` is generated by the LLM (e.g., Llama3.1) in step 1 of our pipeline. Ensure that the generated beliefs strictly map to the exact `QUERIES_PATH` you are using.

## 3. Running Evaluation

Execute the main pipeline. The script runs the full end-to-end NACIR++ evaluation using the optimal hyper-parameter configuration (Dynamic scheduling + ITM Reranking).

```bash
CUDA_VISIBLE_DEVICES=0 python main.py
```

The script will output `Hits@10`, `Recall@10`, `MRR`, and `BRI` at every dialog turn, finally saving the raw ranks to `logs/nacir_plus_ranks_final.npz`.
